# GLOSSKN

## Brand colour palette (fixed — do not deviate)

The GLOSSKN website uses ONLY these colours. No other colour may appear anywhere
in the website: no extra tints, greys, accents, hover shades, gradients stops or
shadow tints outside this list. Translucent versions are allowed only as one of
these colours with an alpha value (e.g. `rgba(64, 64, 64, .2)`).

| Role        | Hex       |
|-------------|-----------|
| Charcoal    | `#404040` |
| Lilac       | `#D5C3E6` |
| Soft lilac  | `#E1CEE4` |
| Mist        | `#EFE9F1` |
| Off-white   | `#F8F5F6` |
| White       | `#FFFFFF` |
| Black       | `#000000` |

The colours in the current glosskn.com Shopify theme are slightly off from this
palette. Do not copy colours from the live site; always use the table above.
Product photo backgrounds should also be `#D5C3E6`.
