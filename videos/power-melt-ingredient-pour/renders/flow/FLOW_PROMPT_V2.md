# Google Flow (Veo 3.1): ingredient plate, no tube (v2)

Veo never draws the product. GLOSSKN adds the real tube, its fill and the label in post.

## Setup

- Mode: **Frames to Video**
- First frame: `empty-set-frame.png`
- Last frame: `empty-set-frame.png` (the same image, so the set ends empty and clean)
- Veo 3.1 Quality, 9:16, 8 s, 4 outputs
- If it's too rushed: one 8 s clip per ingredient (four generations, same first and last frame). This is the better option because each clip gets full time.
